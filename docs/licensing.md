# Licensing

## Status

Draft. The distribution model below is not yet granted by any licence text.

## Source code

The Strata source is licensed under the PolyForm Strict License 1.0.0. That licence permits noncommercial use and does not permit distribution or derivative works.

## Exported games

Strata's intended model is that authors own the games they build and may distribute them commercially, provided the exported game shows a visible Strata credit. This requires a separate runtime grant covering the runtime code embedded in exports. That grant has not been written or reviewed.

## Release blocker

Strata 1.0.0 cannot ship until the runtime grant is written, reviewed, and added to the repository.
