# Changelog

## Unreleased

- Repository foundation: TypeScript configuration, dependency audit, commit linting and CI.
- Dependency audit enforces per-package platform boundaries and normalizes Windows paths.
- Dependabot commits follow the conventional commit format.
- Core package: entity world with typed components, scheduler, events, disposal, results and a fixed timestep.
- Core package: versioned document envelopes with migrations, stable ids and a structured logger.
- Core package: component registry, persistent identity and atomic world snapshots, including partial snapshots.
- Math package: scalar helpers, vectors, quaternions, matrices, seeded PCG32 generator and deterministic trigonometry.
- Scene package: transforms, names, parent hierarchy with cycle protection and versioned scene files.
- Renderer package: WebGPU and WebGL2 sprite rendering with automatic fallback and graphics loss recovery.
- Playground app for exercising the renderer in a browser.
- Input package: keyboard, pointer, touch and gamepad input with rebindable action maps.
- Project package: validated project storage, content-addressed asset library with PNG and WAV import, and scene files.
- Storage package for the browser's origin private file system, and image decoding in the renderer.
- Editor: project launcher, workspace with hierarchy, inspector and viewport, and an editor session package.
- Commands package: context keys with when clauses, command registry, chorded keybindings and fuzzy quick pick.
- Editor: command palette and keyboard shortcuts.
- Editor: undo and redo with merging of continuous edits, and saved-position tracking.
- Tooling: `bun run merge` waits for checks and squash-merges the current pull request.
- Menus package: contributed menus with groups, conditions, check items, submenus and a keyboard and pointer controller.
- Editor: context menu with submenus, type-ahead, touch long-press and keyboard opening, wired to the hierarchy.
- Editor: viewport context menu with picking, entity creation at the pointer and a grid toggle; panning moved to middle drag.
- Editor: sprite component, assets panel with import and drag into the viewport, textured drawing and an image picker in the inspector.
- Scene: register the sprite component so sprites are saved, loaded and restored by undo.
- Editor: duplicate an entity with its descendants (Ctrl+D), undoable.
- Physics package: 2D rigid bodies with box and circle colliders, friction and restitution.
- Gameplay package: player controller. Runtime package: plays a scene at a fixed timestep. Editor: Play mode (F5), generic component inspector, Add Player, Platform and Camera.
- Runtime: Play draws every entity, reports errors and a status line in the Play bar.
- Editor: move, rotate and scale gizmos (W, E, R) and copy, cut and paste.
- Editor: Make player and Make solid presets, audio component with an asset picker, checkbox fields.
- Runtime: audio playback, camera follow with smoothing, player and body counts in the Play bar; Play now moves focus out of text fields.
- Scripting package: TypeScript script API and host. Project: script assets with editing. Editor server: compile and type-check endpoints.
- Editor: script editor with New script, Save and type-check; Play runs the game in a sandboxed frame with TypeScript scripts compiled by the editor server.
- Editor: script IDE with syntax highlighting, live diagnostics, completion, hover documentation and a docs panel, powered by the native TypeScript language server.
- Project: asset folders with create, rename, move and delete. Editor: file tree explorer and a script IDE workbench with tabs, docs and a status bar.
- Editor: resizable panels with remembered sizes, SVG icon set and icon explorer, Rect tool for visual resizing, viewport toolbar and a 2D and 3D mode switch.
- IDE: find and replace, go to line, auto-close brackets, comment toggle, move and duplicate lines, indent selections, bracket matching, go to definition, signature help, rename and format. Context menus now appear above the IDE.
- IDE: test run with a sandboxed runner and Output panel, inline error messages and gutter markers, richer hover, working format with status. Fixes for slow rendering and scroll jumps.
