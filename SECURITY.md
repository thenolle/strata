# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub security advisories](https://github.com/thenolle/strata/security/advisories/new). Do not open a public issue.

Include the affected version, steps to reproduce, and the impact you observed. Fixes are published in a release with credit to the reporter unless you prefer otherwise.

## Scope

Strata opens project files, imports third-party assets, runs scripts and extensions, and synchronises projects with a cloud service. Reports about untrusted project or asset handling, script and extension isolation, content security policy bypass, synchronisation integrity, path traversal and secret leakage are in scope.
