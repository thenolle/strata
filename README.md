# Strata

Strata is a browser-based 2D and 3D game engine with an integrated editor. It is under active development and has no usable release yet.

## Status

Pre-release. The repository currently contains engineering foundations only.

## Requirements

- [Bun](https://bun.sh), version pinned in `.bun-version`

## Development

```bash
bun install
bun run check
```
